# Fitsum AI Keyboard - Amharic Ge'ez & English Android InputMethodService

A 100% offline, privacy-first Android Keyboard (IME) with Amharic Ge'ez phonetic transliteration and English translation candidate suggestions.

## 🚀 How to Build APK on GitHub (Automated)

1. **Push this code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Fitsum AI Keyboard"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/fitsum-ai-keyboard.git
   git push -u origin main
   ```

2. **GitHub Actions Auto Build**:
   - Go to your repository on GitHub.
   - Click the **Actions** tab.
   - You will see the **Build Android APK (Fitsum AI Keyboard)** workflow running automatically!
   - Once completed (takes ~2 minutes), click on the workflow run and download the **Fitsum-AI-Keyboard-Debug-APK** zip artifact from the bottom of the page.

3. **Install on Phone**:
   - Transfer app-debug.apk to your phone or send it via Telegram/Drive.
   - Tap to install, enable **Fitsum AI Keyboard** in *Language & Input Settings*, and set as active keyboard!
